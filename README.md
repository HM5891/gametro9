# Gametro9

Website for Gametro9 — original mobile games, A to Z, in one place. Play on cloud nine.

- `index.html` — home page (games, Token wallet, library)
- `play/chai-empire/` — Chai Empire, playable in the browser
- `favicon.svg` — the Gametro9 logo

Hosted on GitHub Pages. To use gametro9.com later: add a `CNAME` file containing `gametro9.com`, then point the domain's DNS at GitHub Pages.

Status: sample. Payments and sign-in are test mode only.
